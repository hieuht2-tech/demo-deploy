BẮT ĐẦU VỚI BẢN MẪU FOOD MENU

1. Mở thư mục demo-deploy trong VS Code.
2. Dùng Live Server mở index.html. Không mở bằng file://.
3. Đi hai luồng:
   - Công thức -> chi tiết -> lưu/đánh giá -> bộ sưu tập.
   - Thực đơn demo -> giỏ -> đăng nhập -> xác nhận đơn -> lịch sử.
4. Dùng tài khoản tự đăng ký và thông tin người nhận giả.

TÀI LIỆU GIẢNG TIẾP TỪ PROJECT HIỆN CÓ

docs/HUONG_DAN_GIANG_DAY.html
  Bản có thể đọc trên trình duyệt, 10 chặng/trang, ví dụ code và bài thao tác.
docs/HUONG_DAN_GIANG_DAY.pdf

TÀI LIỆU DEPLOY BẰNG GIAO DIỆN GITHUB

docs/HUONG_DAN_DEPLOY_GITHUB_PAGES.pdf
  Upload đúng thư mục -> Pages master/main + root -> Actions -> Visit site.
  Có cập nhật code, Save mờ, queued, lỗi 404, file JSON và storage khác tên miền.
docs/HUONG_DAN_DEPLOY_GITHUB_PAGES.html
  Bản nguồn HTML để chỉnh tài liệu và in lại khi cần.
